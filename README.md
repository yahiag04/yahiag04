## Selected Projects

### [UAV Flight Anomaly Detection](https://github.com/yahiag04/flight-log-anomaly-ml)

Unsupervised anomaly detection on real **PX4 UAV flight logs**, comparing One-Class SVM, Isolation Forest, PCA Autoencoder, and LSTM Autoencoder approaches.

**Held-out ROC-AUC: 0.940**

`Python` · `PyTorch` · `scikit-learn` · `Streamlit`

---

### [Pneumonia CXR Generalization](https://github.com/yahiag04/pneumonia-cxr-generalization)

Bachelor's thesis research on **cross-dataset generalization in chest X-ray classification**.

Five CNN architectures benchmarked across three independent datasets, including calibration analysis, bootstrap confidence intervals, and statistical significance testing using **McNemar** and **DeLong** methods.

**Internal ROC-AUC: 0.990**

`Python` · `PyTorch` · `SciPy`

---

### [Sentinel — Geopolitical RAG](https://github.com/yahiag04/Sentinel)

Retrieval-augmented analysis system built around a vector-indexed document corpus, combining semantic retrieval with API-based services, caching, and persistent storage.

`FastAPI` · `ChromaDB` · `PostgreSQL` · `Redis` · `Docker`

---

### [EnvMonitor](https://github.com/yahiag04/EnvMonitor)

Embedded environmental monitoring system built around the **ESP32**, with calibrated CO sensing, ratio-based alerting, and real-time telemetry streamed to a Node.js backend.

`C++` · `ESP32` · `Node.js`
